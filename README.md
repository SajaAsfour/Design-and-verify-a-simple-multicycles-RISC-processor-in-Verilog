# 🔧 ENCS4370: Multi-Cycle Processor Implementation in Verilog

## 📌 Overview
This repository contains my implementation of **Project #2: Multi-Cycle Processor** for the **Computer Architecture** course at **Birzeit University**. The project focuses on designing and verifying a **multi-cycle RISC processor** in **Verilog**, supporting a subset of a custom instruction set architecture (ISA).

## 🛠 Features
- ✅ **Multi-Cycle Processor Implementation**
- ✅ **16-bit Instruction & Data Memory**
- ✅ **General-Purpose Registers (R0-R7)**
- ✅ **Instruction Types:** R-Type, I-Type, J-Type, and S-Type
- ✅ **Byte-Addressable Memory (Little Endian)**
- ✅ **Branch Prediction & ALU Condition Signals**
- ✅ **Control Unit with Truth Tables & Boolean Equations**
- ✅ **Datapath and Control Path Diagrams**
- ✅ **Testbench for Verification & Simulation**

## 📂 Contents
- 📜 **Source Code:** Verilog implementation of the processor.
- 📝 **Test Programs:** Assembly test cases and machine code.
- 📄 **Report:** Detailed explanation of design choices, control signals, and simulation results.
- 📊 **Simulation & Waveform Outputs:** Snapshots demonstrating execution correctness.

## 🚀 How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/SajaAsfour/Design-and-verify-a-simple-multicycles-RISC-processor-in-Verilog
   ```
2. Open the project in any Verilog simulator.
3. Load the **Verilog file**.
4. Run the provided test programs and verify outputs.
5. Analyze the waveforms to ensure correct execution.
